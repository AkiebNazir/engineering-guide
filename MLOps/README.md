# Machine Learning System Design (MLOps)

This module focuses on how to put Machine Learning models into production. It bridges the gap between a Data Scientist's Jupyter Notebook and a reliable, scalable, low-latency software system. 

It covers both the infrastructure (MLOps) and the architecture of classic ML systems (Search, RecSys, Ads).
