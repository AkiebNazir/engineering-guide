# Beginner API to Postgres

Pulls data from a public REST API (JSONPlaceholder) and loads it into a PostgreSQL database using SQLAlchemy.

## Setup

1. Have a local PostgreSQL running (e.g., via Docker) on port 5432 with user `postgres` and password `password`.
2. Install requirements: `pip install -r requirements.txt`
3. Run the script: `python main.py`
