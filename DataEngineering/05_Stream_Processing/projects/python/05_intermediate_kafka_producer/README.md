# Intermediate Kafka Producer & Consumer

A Kafka pipeline using `kafka-python`, demonstrating producing and consuming JSON events.

## Setup

1. Ensure you have Kafka running locally on `localhost:9092` (e.g., using Docker Compose).
2. Install requirements: `pip install kafka-python`
3. Run the consumer in one terminal: `python consumer.py`
4. Run the producer in another terminal: `python producer.py`
